# 08 · Métricas

**Regla:** sin datos propios, las cifras del one-pager son objetivos, no resultados. Aquí no se inventan metas: se define qué medir.

## Embudo comercial (instituciones)

| Etapa | Qué contamos |
|---|---|
| Contactadas | Instituciones con una conversación iniciada |
| Discovery | Reuniones hechas |
| Demo | Demos hechas, con el decisor presente o no |
| Prueba | Pruebas de concepto acordadas |
| Cliente | Contratos |

Dos datos extra por cuenta: **¿identificamos al decisor?** y **¿cuánto tardamos entre etapas?**

## Embudo del egresado (dentro de una prueba)

Registro → CV adaptado → postulaciones registradas → entrevistas → colocación → permanencia.

## Criterios de éxito de una prueba

Se acuerdan con cada institución antes de empezar. Candidatos a medir:

- Porcentaje de egresados invitados que se registra.
- Porcentaje que usa el copiloto al menos una vez al mes.
- Porcentaje que contesta los chequeos de seguimiento, frente a la tasa de respuesta de su encuesta actual. *Es la medida clave de la trazabilidad.*
- Entrevistas por postulación antes y después de usar el CV adaptado.
- Qué decisiones puede tomar la institución con el reporte que no tomaba antes.

## Hipótesis a validar

| # | Hipótesis | Cómo la probamos |
|---|---|---|
| H1 | Las instituciones no ven el embudo de sus egresados | Preguntarlo en cada discovery |
| H2 | La trazabilidad es el motivo de compra, más que las funciones | Qué parte de la demo genera más interés |
| H3 | El egresado responde los chequeos más que una encuesta | Tasa de respuesta en la prueba |
| H4 | La institución pagará por el premium | Reacción ante la propuesta con precio |
| H5 | El decisor es el corporativo, no el área de empleabilidad | Preguntarlo en cada cuenta |
| H6 | Los hubs y aceleradoras abren puertas a más instituciones | Introducciones que resultan en reunión |

Para H1, H2 y H5, el criterio inicial es que se repitan en las próximas 2 a 3 conversaciones.
